# CommunityHub

A collaborative React project built by our IYF Season 12 team as part of Lesson 15: React Components.

## About the Project

CommunityHub is a simple community platform where users can explore posts, read updates, and interact with content.

The project focuses on understanding and applying React concepts, including:

- Functional components
- Props
- Component reusability
- Rendering lists using `map()`
- Conditional rendering
- Component composition

## Tech Stack

- React
- JavaScript
- Vite
- CSS
- Git and GitHub

## Getting Started

### Prerequisites

Make sure you have Node.js and npm installed.

### Installation

Clone the repository:

```bash
git clone https://github.com/Samcodex-405/iyf-s12-communityhub-team-Samcodex-405.git
```

Navigate to the frontend:

```bash
cd iyf-s12-communityhub-team-Samcodex-405/frontend
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL displayed in your terminal.

## Team Contribution Guidelines

1. Pull the latest changes from `main` before starting new work.
2. Create a separate branch using your GitHub username.
3. Keep individual Lesson 15 exercises inside `frontend/src/exercises/Samcodex-405/`.
4. Place reusable components inside `frontend/src/components/`.
5. Avoid making unnecessary changes to shared files.
6. Commit your changes with clear commit messages.
7. Push your branch and open a Pull Request for review.
8. Request a teammate to review your Pull Request before merging.
